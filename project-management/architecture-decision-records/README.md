# Architecture Decision Records

This directory contains Architecture Decision Records documenting significant technical and process decisions. File names use the pattern `ADR-XXX-*.md` (ADR = Architecture Decision Record) for brevity.

## Format

Each Architecture Decision Record follows the template in [../templates/architecture-decision-record-template.md](../templates/architecture-decision-record-template.md):
- **Title**: Short, descriptive name
- **Status**: Proposed | Accepted | Deprecated | Superseded
- **Context**: What is the issue?
- **Decision**: What was decided?
- **Consequences**: What are the implications?
