# Project documentation

This folder holds **general project documentation**: architecture overviews, API references, user guides, and other material that is not part of the structured project-management workflow.

## What belongs here

- Design and architecture notes for the product or service.
- Onboarding and how-to guides for contributors.
- Generated or hand-written API docs.

## What does not belong here

- Backlog items, sprints, processes, and PM templates — those live under `project-management/`.
- Release history — use `RELEASE_NOTES.md` at the repository root and `project-management/processes/release-notes-process.md`.
